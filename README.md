# 모아랩 첫 출근 FAQ

부경대 동계 현장실습 사전교육에서 사용하는 가상 회사 자료입니다. 공통 미션은 [이슈 #1](../../issues/1)의 내용을 따릅니다. 저장소 밖에서 읽는 경우 [공개 저장소 페이지](https://github.com/ExpandSource/pknu-2026-onboarding-faq)를 엽니다.

1. [계정](docs/accounts.md), [개발 환경](docs/environments.md), [질문과 업무 자료](docs/support.md)에서 근거를 찾습니다.
2. 원본에서 **Fork**를 눌러 본인 사본을 만듭니다. 포크의 브랜치 선택 메뉴에서 `faq/NN`을 만들어 선택합니다. NN 대신 배정받은 번호를 넣습니다.
3. **Add file → Create new file**에서 `faq/NN.md`를 만들고 [FAQ 양식](faq/template.md)의 구조를 사용합니다. 커밋 전에 포크와 브랜치 이름을 확인합니다.
4. 새 PR을 열고 base는 이 원본 저장소의 `main`, compare는 본인 포크의 `faq/NN`으로 선택합니다. 제목은 `FAQ NN: 질문 요약`으로 작성합니다.
5. 짝과 PR 주소를 교환합니다. 짝의 PR에서 **Files changed**를 열어 한 줄에 코멘트를 남깁니다. 질문에 답했는지, 출처가 답을 뒷받침하는지 확인합니다.

실습 파일에는 배정 번호와 가상 문서 내용만 넣어 주세요. 예시 리뷰: “권한 요청 절차가 잘 보입니다. 답변 끝에 멘토 승인 단계도 추가해 주세요.”
